Heft-Einträge: Gleichungen lösen

Alle Einträge, die im Unterricht ins Heft übernommen werden – in der Reihenfolge der Präsentation (Foliennummer in Klammern). Zum Nachholen bei Fehlzeiten oder als Merkblatt.

HEFT 1Gleichung, Variable, Lösung(Folie 14)ABSCHREIBEN
Gleichung = zwei Terme, verbunden durch ein Gleichheitszeichen. Beispiel: 2x + 3 = 11
Variable = Platzhalter für eine Zahl (meist x).
Lösung = die Zahl, die beim Einsetzen eine wahre Aussage ergibt.
Beispiel: 2x + 3 = 11 hat die Lösung x = 4, denn 2 · 4 + 3 = 11  (wahr).
x = 5 ist keine Lösung, denn 2 · 5 + 3 = 13 ≠ 11  (falsch).
HEFT 2Probe, Grundbereich, Lösungsmenge(Folie 16)ABSCHREIBEN
Probe: Lösung in die Ausgangsgleichung einsetzen, beide Seiten ausrechnen – links = rechts?
Grundbereich G: Zahlen, die eingesetzt werden dürfen, z. B. ℕ (natürliche), ℤ (ganze), ℚ (rationale Zahlen).
Lösungsmenge L: alle Lösungen aus G. Schreibweise: L = {4}   Keine Lösung: L = { }
Beispiel: 2x = 5   in ℕ: L = { }  ·  in ℚ: L = {2,5}, denn 2 · 2,5 = 5
HEFT 3Rückwärtsrechnen (Pfeilschema)(Folie 28)ABSCHREIBEN
Jede Rechenoperation hat eine Umkehroperation: + ↔ − und · ↔ : .
Beispiel: 3x + 5 = 20
vorwärts:
x· 3⟶+ 5⟶20
rückwärts:
20− 5⟶15: 3⟶5
  also x = 5
Merke: Beim Rückwärtsrechnen fängst du hinten an und machst jede Rechnung mit der Umkehroperation rückgängig.
HEFT 4Äquivalenzumformungen (Waageregel)(Folie 40)ABSCHREIBEN
Eine Gleichung ist wie eine Waage im Gleichgewicht. Ich darf auf beiden Seiten
+dieselbe Zahl (oder denselben Term) addieren oder subtrahieren,
·mit derselben Zahl multiplizieren oder durch dieselbe Zahl dividieren (nicht 0).
Das heißt Äquivalenzumformung – die Lösung bleibt gleich. Die Rechnung schreibe ich hinter einen senkrechten Strich: | − 3
2x + 3=11| − 3
2x=8| : 2
x=4

HEFT 7Sonderfälle und Brüche(Folie 76)ABSCHREIBEN
Verschwindet x beim Umformen, entscheidet die übrig gebliebene Aussage:
falsche Aussage (z. B. 3 = 7) → keine Lösung: L = { }
wahre Aussage (z. B. 6 = 6) → unendlich viele Lösungen: L = ℚ
Brüche: beide Seiten mit dem Hauptnenner multiplizieren.  x2 + x3 = 10 | · 6 → 3x + 2x = 60 → 5x = 60 | : 5 → x = 12

HEFT 9Formeln umstellen(Folie 107)ABSCHREIBEN
Eine Formel stelle ich um wie eine Gleichung. Die gesuchte Größe behandle ich wie x, alle anderen Buchstaben wie Zahlen.
u=2a + 2b| − 2b
u − 2b=2a| : 2
(u − 2b) : 2=a⇄ Seiten tauschen
a=(u − 2b) : 2
Kontrolle mit Zahlen: u = 20, b = 4 → a = (20 − 8) : 2 = 6
