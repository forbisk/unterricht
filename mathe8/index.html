Vom Term zur Gleichung

Term

3x + 5
Setze x = 5 ein: 3 · 5 + 5 = 20
Der Term hat dann den Wert 20.

Gleichung

3x + 5 = 20
Frage: Für welches x kommt 20 heraus?
Das ist eine Gleichung – wir suchen die Lösung.
🔎Term = Rechenausdruck.   Gleichung = zwei Terme mit „=“ – und oft eine gesuchte Zahl.

Die Waage – ziehen, klicken, ausprobieren

Demo: Kisten (x) und Gewichte (1) können aus der Palette auf eine Schale gezogen werden; Klick auf einen Gegenstand in der Schale nimmt ihn nur dort weg → Waage kippt, Gleichheitszeichen wird zu ≠.

Buttons „auf beiden Seiten“ halten das Gleichgewicht. Ziel: eine Kiste allein auf einer Seite. Beispiel 2x + 3 = 11: −1 dreimal (bzw. „−3“), dann : 2 → x = 4.

„x verraten“ zeigt das Gewicht einer Kiste. Das Protokoll rechts unten notiert die Schritte schon in der späteren Schreibweise.

u=2a + 2b| − 2b
