# Unterrichtsmaterialien

Offline nutzbare, deutschsprachige Unterrichtswebsites für die Theodor Fontane Gemeinschaftsschule.

Veröffentlicht als GitHub Pages unter: https://forbisk.github.io/unterricht/

Die Veröffentlichung enthält ausschließlich Schülerseiten und benötigte Laufzeit-Assets; Lehrermaterial, Lösungsseiten und Referentenfenster sind nicht enthalten.
