Division ist die Umkehrung der Multiplikation

Entdecken mit der Umkehr-Maschine. Oben steht eine Multiplikation (z. B. (−3) · 4 = −12). Die Pfeile erzeugen die beiden Umkehraufgaben: (−12) : 4 = −3 und (−12) : (−3) = 4.

Und wenn man durch eine negative Zahl teilt?

Wir nutzen die Umkehraufgabe: Welche Zahl mal (−4) ergibt …?

(−3) · (−4) = 12⇒12 : (−4) = −3+ : − = −
3 · (−4) = −12⇒(−12) : (−4) = 3− : − = +
(−2) · (−4) = 8⇒8 : (−4) = −2+ : − = −
2 · (−4) = −8⇒(−8) : (−4) = 2− : − = +

Erst die Multiplikation zeigen (kennen die Schüler), dann die Umkehrung aufdecken lassen. Die Schüler sollen die Division vor dem Aufdecken nennen.

Ziel: Die Vorzeichenregeln der Division sind dieselben wie bei der Multiplikation.

Division an der Zahlengeraden

Modell: Der Pfeil von 0 bis zum Dividenden wird in gleich große Sprünge zerlegt (so viele, wie der Betrag des Divisors angibt). Ein Sprung ist das Ergebnis. Ist der Divisor negativ, wird das Ergebnis an der 0 gespiegelt (Vorzeichenwechsel).

Beispiele durchklicken: (−12) : 4, 12 : (−4), (−12) : (−4). Dann „Neue Aufgabe“ – die Klasse sagt das Ergebnis voraus.

Dezimalzahlen: Komma verschieben

Schritt für Schritt: 1) Vorzeichen bestimmen, 2) Komma bei beiden Zahlen gleich weit verschieben, bis der Divisor eine ganze Zahl ist, 3) rechnen, 4) Vorzeichen davor.

Vergleich zur Multiplikation: Auch dort galt „Vorzeichen und Komma getrennt“.

Beispiele: Dezimalzahlen dividieren

(−7,5) : 0,5
  1. Vorzeichen: − : + → −
  2. Komma 1 Stelle: 75 : 5 = 15
  3. Ergebnis: (−7,5) : 0,5 = −15
  4. Probe: (−15) · 0,5 = −7,5 ✓
(−0,36) : (−0,6)
  1. Vorzeichen: − : − → +
  2. Komma 1 Stelle: 3,6 : 6 = 0,6
  3. Ergebnis: (−0,36) : (−0,6) = 0,6
  4. Probe: 0,6 · (−0,6) = −0,36 ✓

Beide Beispiele ins Heft (unter Heft-Eintrag 2 oder als Übungsbeispiel). Beim zweiten Beispiel: Nach dem Verschieben steht noch ein Komma im Dividenden – das ist erlaubt (3,6 : 6 wie gewohnt rechnen).
